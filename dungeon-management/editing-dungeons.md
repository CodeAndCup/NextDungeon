# Editing Dungeons

### Start an editing server:

The first step to edit a dungeon, is to load one floor of them in edit mode.\
To do that, you just need to execute the command `/nd admin edit <dungeon> <floor>`\
\
\
, **dungeon** is the ID of the dungeon that contains the floor that you want to edit and **floor** the ID of the floor that you want to edit.

> As same as normal dungeon loading, edit dungeon can take few minutes to load.

After that the edit server load and you have been teleported, you can edit the world normally.\
Now, if you want to edit triggers (events) and actions, you are able to start a web editor by using the command `/nd admin webeditor start` and that will give you a URL to your editor.
