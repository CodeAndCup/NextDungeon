# Feature Overview

### Core Features

#### 1. Custom Dungeon Creation & Management

* Create and edit dungeons with multiple floors and unique layouts.
* Support for procedural or hand-crafted dungeon designs.
* Manage dungeon properties such as difficulty, rewards, mob spawns, and more.

#### 2. Visual Editor (Blockly Web Editor)

* Design dungeons visually using a browser-based Blockly editor.
* Drag-and-drop interface for configuring dungeon logic, events, and triggers.
* Export and import dungeon designs for easy sharing and collaboration.

#### 3. CloudNet or ASP or Vanilla Integration

* Seamless support for CloudNet to dynamically spin up and manage dungeon instances. It's an efficient resource usage and scalability for large servers or networks.
* We also support Advanced Slime Paper made by InfernalSuite if you want to use an optimized world.
* If you don't want one of them, vanilla worlds are also supported but not recommended due to performance.

#### 4. Plugin Integrations

* **Parties Plugin**: Enable group play and shared rewards.
* **MMOCore**: Integrate RPG elements such as classes, skills, and experience.
* **MythicMobs**: Use custom mobs, bosses, and abilities inside dungeons.
* Supports additional plugins for enhanced gameplay and mechanics.

#### 5. Configurable Experience

* Extensive configuration options for both global plugin settings and individual dungeons.
* Separate config files for main plugin settings, dungeon templates, and floor-specific logic.
* Example configs included for quick setup.

#### 6. Powerful Commands & Permissions

* Intuitive commands for dungeon management, admin tools, and player interaction.
* Granular permission nodes give fine control over who can access features.

#### 7. Guides & Tutorials

* Step-by-step guides for installing, configuring, and designing dungeons.
* Advanced tutorials for custom mechanics, integrations, and troubleshooting.

#### 8. Robust Troubleshooting & Documentation

* Comprehensive FAQ and troubleshooting resources.
* Detailed documentation for every major feature and integration.

#### 9. Coming Soon: Developer API

* Planned API for extending plugin functionality and integrating with custom server solutions.
