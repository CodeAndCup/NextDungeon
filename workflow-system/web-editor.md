# Web Editor

The web editor is based on Blockly.

Blockly is a visual programming editor made by Google.

If you don't know blockly or your not super friendly with, you can visit the user guide of it: [https://developers.google.com/blockly/guides/get-started/workspace-anatomy?hl=fr](https://developers.google.com/blockly/guides/get-started/workspace-anatomy?hl=fr)
