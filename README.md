# What is NextDungeon

**NextDungeon** is a powerful, extensible dungeon plugin for Spigot/Paper servers on Minecraft **1.21.4**. It lets you design, deploy, and run fully custom dungeons with multiple floors, visual trigger automation, and deep integration with popular plugins — all shared seamlessly across a whole server network.

<!-- INSERT HERE: screenshot of the dungeon gate menu -->

Dungeon content is synchronised across every server in your network in real time, so all lobbies show the same up-to-date dungeons. Each floor runs on its own dedicated server, giving players an isolated, lag-free environment.

### Key Highlights

* **Multi-floor dungeons** — each dungeon holds one or more floors, each with its own world, requirements, rules, and progression.
* **Visual trigger automation** — attach behaviour to a floor without any coding. Triggers (block click, region entry, entity death…) run sequences of actions (send a message, teleport, summon mobs, end the run…) with optional logic.
* **Browser-based editor** — build and edit your workflows by dragging blocks together in your browser while in edit mode.
* **Network-wide sync** — dungeons, instances, queues, and player profiles stay consistent across the whole network.
* **Dedicated instances** — each floor run gets its own server, created on demand and cleaned up automatically.
* **Queue system** — players and parties queue for full floors and are sent in as space opens up.
* **Revive & ghost system** — downed players become ghosts and can be revived by teammates before they lose a life.
* **Party play** — works with AlessioDP Parties or the built-in party system.
* **Level & progression requirements** — gate floors behind an MMOCore level and prerequisite floors.
* **Player profiles** — completed floors and per-run stats (kills, deaths, time) are saved per player.

### Supported Platforms

NextDungeon targets **Spigot 1.21.4** and compatible forks (Paper, Purpur). The proxy side supports both **Velocity** and **BungeeCord**.
